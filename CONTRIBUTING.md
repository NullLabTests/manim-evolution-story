# Contributing

Thank you for your interest in contributing to this project.

## How to Contribute

1. **Fork** the repository
2. **Create a feature branch**: `git checkout -b feature/my-idea`
3. **Make your changes**
4. **Test** by rendering at least one scene: `make render-scene S=BigBangScene`
5. **Commit** with a clear message
6. **Push** and open a Pull Request

## Ideas for Contributions

- Add voiceover narration to the master video
- Create new chapters (e.g., Age of Dinosaurs, Age of Exploration)
- Improve existing animations with more Manim features
- Add a new scene theme (e.g., botany, geology, astronomy)
- Translate text labels to other languages
- Optimize rendering performance
- Add more 4K upscales with different filter chains

## Code Style

- Follow PEP 8 for Python code
- Use existing color constants from the palette when adding new elements
- Keep animations in the 10-25 second range per chapter
- Add docstrings to new scene classes and helper functions

## Questions

Open an issue if you have questions or need guidance.
